# Lost Logbook (working title)

Playable mobile-web prototype of an original fishing RPG: cast, hook, fight, sell, gear up, find the three parts of
the lure, land the legend. Phaser 3 + TypeScript + Vite. Portrait phone layout; mouse and SPACE work on desktop.

- Design brief: `docs/DESIGN.md`
- Every tuning number: `docs/TUNING.md`
- Live build: https://extremehomesbk-coder.github.io/lost-logbook/

```
npm install
npm run dev      # local dev server
npm run check    # lint + typecheck + tests + playthrough simulation + build
```

Placeholder art and no sound by design. Saves live in your browser (localStorage); export a save code from the Menu
screen before clearing browser data.
